kterm for Kindle, GPL-3.0.
Based on kterm 2.6 by Bartek Fabiszewski: https://github.com/bfabiszewski/kterm
Changes: GTK+ 3 and VTE 0.84 on the Kindle X server, compact keyboard layout
(split in two halves in landscape), shortcut bar with panel and keyboard
buttons and prefix shortcuts, panel (SSH connections, found in the local
network by multicast DNS (kterm-mdns), with keys to choose, make and
install, and disconnecting; settings: font size, screen orientation,
refresh, full refresh, tmux integration, voice input, shortcuts), tmux
integration (sessions offered after ssh, copy mode asked over a shared
ssh connection),
preview mode (taps on the top or bottom third turn a page), touch gestures
(scrolling, long press to copy, paste button while the program waits for
input, two finger right click), fewer screen refreshes to save the battery,
full refreshes clearing ghosting, system keyboard (pinyin) bridge, voice
input: typing from a phone through a web page (voice.c), KPM packaging.
Icons: Material icons by Google (Apache 2.0). QR codes: QR Code generator
library by Project Nayuki (MIT License, qrcodegen.c). Icons of the
phone page: Lucide (ISC License); its styles: Tailwind CSS (MIT License).
The complete modified source accompanies this package as source.tar.gz.

libvte-2.91.so.0 is VTE 0.84.1 (LGPL-3.0-or-later), from
https://download.gnome.org/sources/vte/0.84/vte-0.84.1.tar.xz
(sha256 aca1caa8478aebcdbb1d67897fb3511eb7601debae6810e16a15b6fa25f31ac8),
built by kindle/build-vte.sh with the patches in kindle/vte/ (both in
source.tar.gz).
